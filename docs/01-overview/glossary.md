# Glossary

## Terms
- Board: a collaborative canvas workspace
- Room: collection of users and session state for a single whiteboard instance
- Session: durable board state snapshot or live collaboration window linked to a room
- Stroke: a drawing operation representing freehand lines or shapes
- Element: a canvas object such as text, rectangle, circle, or path
- Presence: user connection status and room membership metadata
- Undo/redo: user-scoped history of operations
- Export: conversion of the current board into PNG or SVG output
- Namespace: logical Socket.IO room or channel partition for a board session

## Status
This glossary is a design reference; several terms are not yet implemented in code.
