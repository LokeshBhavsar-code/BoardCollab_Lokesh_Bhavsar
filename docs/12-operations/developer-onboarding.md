# Developer Onboarding

## Purpose
Enable a new developer to start working on BoardCollab without needing extra tribal knowledge.

## Prerequisites
- Docker Desktop or Docker Engine
- Git
- Node.js for local toolchain work if needed

## Setup checklist
- clone the repository
- copy environment file
- review `.env` values
- start Docker Compose
- run the backend health check

## Implementation status
Status: onboarding documents are intentionally based on the current repo foundation.
