# Acceptance Criteria

## Purpose
Document the feature-level exit criteria expected for BoardCollab implementation milestones.

## Examples
- user can register and authenticate
- authorized user can create and join room
- room members can draw in real time
- duplicate or stale events are handled without corruption
- reconnect restores room session safely

## Current repo baseline
The repository does not yet satisfy these criteria.
